# Mealify - Restaurant Landing Page

Mealify is a responsive restaurant landing page designed to provide users with an engaging and appetizing browsing experience. The site showcases a modern design, highlighting various sections such as chefs, gallery, and contact information.

## 🚀 Live Demo

[Mealify Live](https://abdunader.github.io/Mealify-IEEE/)

## 🛠️ Built With

- **HTML5** – Semantic markup for structured content.
- **CSS3** – Styling with responsiveness in mind.
- **Font Awesome** – Icons for enhanced visual appeal.
- **Google Fonts** – Custom typography for a modern look.

## 📂 Features

- **Responsive Design**: Ensures optimal viewing on various devices.
- **Chef Profiles**: Highlights professional chefs with images and descriptions.
- **Gallery Section**: Displays a variety of dishes with enticing visuals.
- **Contact Form**: Allows users to get in touch or make reservations.
- **Newsletter Subscription**: Users can subscribe for updates and offers.
